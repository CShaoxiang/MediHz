# Overview
A reference and guide for stylisation and formatting of the MediHz frontend layout.

## `Annotation Wireframe`
The main page of which users are intended to conduct annotations

- Two sidebars are provided which allow for both file navigation and prepackaging of tags

- Users will be able to scroll or view the audio file in its entirety. Clicking and drags areas of which they wish to annotate

- If multiple users were to be working on the same file, they will be able see live updates of new annotations

- The audio annotations can then be exported out of the application in a JSON file

## `File Organisation Wireframe`

- Multiple audio files can be organised and presented in a google drive like format

- Users will have an enhanced view of the audio files that have been uploaded and enter any file to annotate when clicked

- If need they can then export all audio files in separate json files from this page
